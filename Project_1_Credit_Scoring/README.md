# Анализ кредитного риска и профилирование заемщиков

## Описание проекта (Business Value)
Проект выполнен в рамках исследования надежности заемщиков для настройки банковской скоринговой модели. 
**Цель:** Выявить влияние семейного положения, количества детей и целей кредита на факт возврата кредита в срок (Default Rate).

## Стек технологий
- **Инструменты:** Python, Pandas.
- **Методы:** Предобработка данных (работа с пропусками через `.transform`, удаление дубликатов), категоризация данных, когортный анализ метрик риска через `.agg()`.

## Ключевые бизнес-выводы
1. **Фактор семьи:** Официальный брак исторически снижает риск дефолта (7.5% просрочки против 9.7% у неженатых). Наличие детей повышает финансовую нагрузку и риск просрочки (до 9.4% при 2 детях).
2. **Фактор цели:** Кредиты, обеспеченные залогом (недвижимость - 7.2%), показывают наибольшую возвратность. Высокорисковыми являются автокредиты и кредиты на образование (свыше 9.2%).
